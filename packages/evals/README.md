# 评测集

`scripts/evaluate.py` 运行固定日期 2026-10-18 的合成开发样例，覆盖相对日、自然周、明确日期、歧义、否定和未支持业务。不能替代至少 100 条脱敏真实问法或三名管理员 UAT。

真实评测 JSON 格式：`{"source":"real-deidentified","cases":[{"text":"明天课表","start":"2026-10-19","end":"2026-10-19"}]}`。不执行的问句 start/end 为 null。日期上下文固定为 2026-10-18；其他上下文另建版本。使用 `python scripts/evaluate.py --file 路径` 验证，不上传个人信息。

先划分开发集与独立验收集，再冻结真实验收版本。本脚本只评估路由及日期，不证明教务结果正确，不能把合成样例通过率当成真实业务解决率。
